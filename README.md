# Lab Front

Адаптивный клиент агрегатора анализов на Expo + React Native Web. Одна кодовая база покрывает iOS/Android и web/PWA.

Реализованы регистрация пациента/врача, профиль со специализацией, загрузка с камеры, из галереи и файлов, история, унифицированные показатели, ИИ-сводка с дисклеймером, отправка/печать и запрос консультации выбранного врача.

```bash
cp .env.example .env
corepack enable
pnpm install
pnpm web
```

Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm build`.

> Это MVP, не медицинское изделие. Автоматическая оценка не ставит диагноз. Перед публикацией в App Store нужны privacy manifest, политика конфиденциальности, верификация медицинских сценариев и юридическая оценка для целевых стран.
